# Derivations

Scratch derivations used by the project. These should eventually be replaced by symbolic notebooks and reproducible scripts.

## 1. Regular-center scaling

Write

\[
f(r)=1-\frac{2M G_{\rm diag}(r)}{r}.
\]

A regular spherical center requires

\[
f(r)=1+O(r^2).
\]

Therefore

\[
\frac{G_{\rm diag}(r)}{r}=O(r^2)
\]

and hence

\[
\boxed{G_{\rm diag}(r)=O(r^3)}.
\]

If

\[
G_{\rm diag}(r)\sim C r^p,
\]

regularity requires \(p\ge3\).

## 2. De Sitter core

Set

\[
f(r)=1-\frac{r^2}{\ell^2}.
\]

This is the static patch of de Sitter space near the origin.

The curvature invariants are

\[
R=\frac{12}{\ell^2},
\]

\[
R_{\mu\nu}R^{\mu\nu}=\frac{36}{\ell^4},
\]

and

\[
R_{\mu\nu\rho\sigma}R^{\mu\nu\rho\sigma}
=
\frac{24}{\ell^4}.
\]

All remain finite.

## 3. Hayward small-radius expansion

Take

\[
f(r)
=
1-
\frac{2G_NMr^2}{r^3+2G_NM\ell^2}.
\]

For

\[
r^3\ll2G_NM\ell^2,
\]

expand the denominator:

\[
\frac{1}{r^3+2G_NM\ell^2}
=
\frac{1}{2G_NM\ell^2}
\left[
1-\frac{r^3}{2G_NM\ell^2}
+O(r^6)
\right].
\]

Then

\[
f(r)
=
1-\frac{r^2}{\ell^2}
+O(r^5).
\]

Thus the center is de Sitter-like.

## 4. Diagnostic screened coupling for Hayward

Equate

\[
1-\frac{2M G_{\rm diag}(r)}{r}
=
1-
\frac{2G_NMr^2}{r^3+2G_NM\ell^2}.
\]

Then

\[
\boxed{
G_{\rm diag}(r)
=
G_N
\frac{r^3}{r^3+2G_NM\ell^2}
}.
\]

So

\[
G_{\rm diag}(r)\to G_N
\qquad(r\to\infty)
\]

and

\[
G_{\rm diag}(r)
\sim
\frac{r^3}{2M\ell^2}
\qquad(r\to0).
\]

## 5. Why a repulsive core can appear

Using a Newtonianized diagnostic potential,

\[
\Phi(r)\sim-\frac{M G_{\rm diag}(r)}{r},
\]

take

\[
G_{\rm diag}(r)=Cr^p.
\]

Then

\[
\Phi(r)=-MC r^{p-1},
\]

and

\[
a_r
=
-\frac{d\Phi}{dr}
=
+MC(p-1)r^{p-2}.
\]

For \(C>0\) and \(p>1\), the sign is outward.

This calculation is only heuristic inside a black hole; the covariant statement must be made using geodesic deviation and the effective stress tensor.

## 6. Inner-horizon continuity argument

Suppose

\[
f(\infty)>0,\qquad f(0)>0.
\]

For a non-extremal outer horizon \(r_+\),

\[
f(r_+)=0
\]

and \(f\) changes sign across the horizon. Immediately inside, take \(f<0\).

Since \(f(0)>0\), continuity requires at least one additional radius \(r_-\) satisfying

\[
f(r_-)=0.
\]

Hence a second horizon is generic for static regular-core metrics.

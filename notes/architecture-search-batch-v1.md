## 2. 介入通信の対照：真の3+1D局所source

自然単位で、球半径aのsourceを

```math
J_b(t,r)=(-1)^b\lambda f(t)\frac{\delta(r-a)}{4\pi a^2},\qquad
f(t)=\sin^4(\pi t/T)\quad(0<t<T)
```

とし、それ以外ではf=0とします。場全体は四次元massless scalar、運動方程式は4D波動方程式です。薄い球殻sourceは空間的な理想化で、四次元の局所製造装置まで作ったのではありません。
送信bit以外は同じ初期真空、a、T、lambdaです。球対称性はこの対照にだけ課します。

4Dの遅延Green関数 `delta(t-|x|)/(4 pi |x|)` を角積分すると、R>aで

```math
\phi_b(t,R)=\frac{(-1)^b\lambda}{8\pi Ra}
\int_{R-a}^{R+a} f(t-s)\,ds.
```

場の応力はsource以外で通常のcoherent-state応力。駆動中のWard項を落とさず、放射エネルギーはT=2aの対照で `35 lambda² T/(1024 pi a²)>0` です。
ポンプ・殻・実際の検出器の全応力とGの反作用は未計算で、test-field近似と記録します。

a=1,R=5,T=2では先端到達はt=4。過去のt=-1で両方の平均場は厳密に0です。
独立な分散1のGaussian meterを**読み出しの追加模型**として採用すれば

```math
P_0(Y)=P_1(Y)=\frac{e^{-Y^2/2}}{\sqrt{2\pi}},\qquad D_{\rm past}=0.
```

実際のdetector Hamiltonianやnoise kernelから分散1を導いたとはしません。未来のt=6では平均が `±3 lambda T/(64 pi Ra)` となり、全結果のTV距離は正です。
受信を未来へずらしたこの差を、過去通信の成功へ読み替えません。成功試行の事後選別も行いません。

**出典と追加作業：** [SM]は場の通信・因果依存と相関の区別の参考。上の球殻sourceとGaussian meterの具体式は今回の解析・対照設計です。[SM]の実験や検出器模型の再現とはしません。

## 3. 回転型：共変g_ttの符号と、過去通信を混同しない

[Teo]の定常軸対称の形式を、proper-radial座標xで

```math
ds^2=-N^2dt^2+Q^2dx^2+R^2[d\theta^2+\sin^2\theta(d\phi-\omega dt)^2]
```

と書きます。N,Q,R>0、tは単一値の実座標、時間をずらす口の同一視は**なし**とします。球面座標の極の縮退は座標上のもので、別chartへ移ればよいです。
計量の全4×4行列を反転すると

```math
g^{tt}=-N^{-2}<0,\qquad
n=N^{-1}(\partial_t+\omega\partial_\phi),\qquad g(n,n)=-1.
```

したがってtは時間関数で、nで選ぶ未来方向の因果曲線ではdt>0。**この大域条件の下で、同じ外部時計の過去へ至る経路はありません。**
`g_tt=-N²+R² sin²(theta) omega²` が正になるエルゴ領域の存在は、この結論と矛盾しません。

比較はN=Q=1,R=sqrt(b²+x²),omega=2J/R³,b=1、J=0,1/4,1,10、x=0,1,5の12点。
この関数選択はTeoの形式の特化で、Teo論文の特定の例を全く同じに再現したとはしません。存在するエルゴ領域を消さずに検算します。
厳密なエルゴ面上の零が浮動小数の丸めで正に見える負例に対応し、その成分を有理式で組み立ててから独立数値逆行列を計算します。

**範囲：** 全回転ワームホールの禁止ではありません。時間差付き接続や周期時間を導入すると、大域的tという前提が変わり、別候補になります。
全renormalized支持源は未供給ですが、この特定案の因果障害を示すために成功装置として補う必要はありません。

## 4. 薄殻：四次元Israel接合の半径方向安定性

[PV]の二つのSchwarzschild外部 `f(r)=1-2M/r` を半径a0>2Mで接続します（G=c=1）。
三次元timelike殻に集中する分布的応力を含む**四次元**の古典接合模型です。2D共形場への置換ではありません。

```math
\sigma_0=-\frac{\sqrt{1-2M/a_0}}{2\pi a_0},\qquad
p_0=\frac{1-M/a_0}{4\pi a_0\sqrt{1-2M/a_0}}.
```

σ、pは幾何が要求する異常な表面物質です。正常な量子状態の繰込み応力として供給したものではありません。
保存則 `sigma'=-2(sigma+p)/a` と局所EOS `p'=eta sigma'` により

```math
V(a)=1-\frac{2M}{a}-(2\pi a\sigma)^2,\qquad
\dot a^2+V(a)=0,
```
```math
a_0^2V''(a_0)=-2\left[2\mu+\frac{\mu^2}{1-2\mu}
+(1+2\eta)(1-3\mu)\right],\quad \mu=M/a_0.
```

半径方向線形安定の条件はV''>0。[PV] Eq.(27)の再導出です。etaはdp/dsigmaで、異常な殻で自動的に物理的音速の二乗と解釈しません。

### 4.1 eta∈[0,1]の障害は有限走査だけによらない

`N=-a0² V''(1-2mu)/2` は

```math
N=1-3\mu+3\mu^2+2\eta(1-5\mu+6\mu^2).
```

0<=mu<=1/3ではeta=0が最小で `N=3(mu-1/2)²+1/4>0`。
1/3<=mu<1/2ではeta=1が最小で `N=15(mu-13/30)²+11/60>0`。
よって領域全体でV''<0。`mu=i/200 (i=0..99)`、`eta=j/20 (j=0..20)` の2,100点は厳密有理数でこの証明を照合します。
**Cの対象は、同じEOS範囲・外部物質流なし・能動制御なしで半径方向安定を要する反復利用設計です。**
これは全ての一回限りの信号、非線形安定化、別の殻や場の禁止ではありません。

### 4.2 仮定を変更すると、部分的に安定領域が残る

eta=4では、安定条件は `51 mu²-43 mu+9<0`、すなわち

```math
\frac{43-\sqrt{13}}{102}<\mu<\frac{43+\sqrt{13}}{102}.
```

同じ100点のmu走査では14点が安定。mu=2/5でa0²V''=2/5です。
この変更を `assumption_changes` に明示し、**B**とします。材料の実現性、非球対称モード、口の運動と時間差、過去の記録を含む量子確率は未構成です。

反証側ではV''の式をコピーせず、線形EOSを積分した

```math
\sigma(a)=C+(\sigma_0-C)(a_0/a)^{2(1+\eta)},
\quad C=(\eta\sigma_0-p_0)/(1+\eta)
```

からポテンシャルを再構成し、数値二階微分を行います。静的接合V=V'=0と安定性符号も照合します。

## 5. FKZリングの条件付き経路

[FKZ]の弱場・遠距離近似を使い、リング半径a、殻の短半軸R、口間隔Lについて

```math
I_C\simeq\frac{GM}{ac^2}\left[\arctan(a/R)-a/L\right],
\quad B_{\rm opt}\simeq L/c,
\quad t_3-t_0=B_{\rm opt}-(e^{I_C}-1)t_2.
```

a∈{1,10} m、R/a∈{10,30}、L/R∈{100,1000}、M∈{10³,10¹²,10²⁰} kgの24点で評価します。
I_Cを正にし形式上の帰還差を負にできますが、**全ての点が同じ未供給の負の線源 `-c⁴/(4G)` を要求します。**
時計の式のonsetは製造時間ではなく、長時間まで弱場の量子状態が保たれるという誤差保証もありません。
この模型の透過率を別幾何から輸入せず、過去のP0/P1はnullです。Bを維持します。

検証側はarctanを再使用せず、無限遠からの調和ポテンシャルの積分 `integral_(R/a)^infty dz/(1+z²)` と時計の比から照合します。

## 6. 有限Casimir装置と厚いcollar

### 6.1 独立平行板セルの支持源置換

[CM]の近平坦Maxwell真空と静的DEC支柱を使います。`E_C=-pi² hbar c A/(720 d³)`、引力F=3|E_C|/d。
支柱面積を変えても `E_strut>=F d=3|E_C|`、従って `E_total>=2|E_C|>0` です。
12点の面積・間隔・支柱面積率を調べ、エネルギー微分から求める独立な力とも一致します。
**独立したこのセルの全エネルギーを足し、負の総線エネルギー源に置換する設計だけをCとします。** 正のADM質量を持つワームホールや、全てのCasimir機構の禁止ではありません。

### 6.2 厚いcollarの必要条件を通ることと、量子支持解の存在は別

四次元計量 `ds²=-c²dt²+dx²+r(x)²dOmega²`、`r=b+sqrt(x²+epsilon²)-epsilon` を使います。
自然単位の中央では

```math
8\pi G(\rho,p_r,p_\perp)=
\left((1-2b/\epsilon)/b^2,-1/b^2,1/(b\epsilon)\right).
```

[FE]の4D timelike QEIを、曲率・境界から離れた短時間の局所平坦近似として適用します。
`g(u)=2 cos²(pi u/2)/sqrt(3)` (|u|<1) の規格化積分は1、二階微分積分はpi⁴/3。
これは端でC1の関数なので、smoothなH²近似の極限として使い、不連続なsourceを量子演算子へ無断で代入しません。
`cT=f epsilon` とすると、下限は `-N hbar c pi²/[48(f epsilon)^4]`。
薄層の先頭の必要条件は

```math
\epsilon_{\max}^3=\frac{N\pi^3}{12f^4}\ell_P^2 b.
```

b∈{10^-6,10^-3,1} m、N∈{1,100}、epsilon/epsilon_max∈{1/4,1/2,1,2}、f=.01の24点です。
中央の正確な要求密度と局所平坦下限を比較すると18点が条件を通り、6点は不適合。
**18点に対応する量子状態を構成したわけではありません。** 曲率補正・全支持装置・安定性・時間差は未解決で、この族全体はBです。
[FR]の単一スケールと薄い負エネルギー領域の区別を保持し、平坦QEIを全曲率での厳密定理に拡大しません。

# Regularized-Lovelock Scalar-Tensor Benchmark: Regular Background, Unstable Perturbations

This note evaluates a four-dimensional scalar-tensor route that avoids the
curvature-projector degeneracy of the explicit rational pure-gravity lift.

Primary references:

- P. G. S. Fernandes,
  *Singularity resolution and inflation from an infinite tower of regularized
  curvature corrections*, Phys. Rev. D **112**, 084028 (2025),
  arXiv:2504.07692, DOI: 10.1103/763p-htct.

- A. De Felice and S. Tsujikawa,
  *Instability of regular planar black holes in four dimensions arising from
  an infinite sum of curvature corrections*, Phys. Rev. D **112**, 064023
  (2025), arXiv:2507.11803, DOI: 10.1103/cbyk-b46n.

## 1. Why this candidate was considered

The theory is obtained by a well-defined dimensional regularization of each
Lovelock density. At every order the four-dimensional result is a
shift-symmetric Horndeski scalar-tensor Lagrangian.

Therefore:

- the four-dimensional action is local and covariant;
- the field equations are second order;
- no curvature-direction projector such as
  \(I_{C^3}/I_{C^2}\) is needed to define the action;
- an infinite tower of corrections can be resummed.

This makes it an important alternative to the nonpolynomial rational lift.

## 2. Infinite-tower action

The theory has the schematic action

\[
S
=
\frac{1}{16\pi}
\int d^4x\sqrt{-g}
\left[
-2\Lambda+R
+
\frac1{\ell^2}
\sum_{n=2}^\infty
c_n\ell^{2n}\mathcal L^{(n)}
\right],
\]

where each \(\mathcal L^{(n)}\) is a Horndeski Lagrangian generated by the
regularized \(n\)-th Lovelock invariant.

With

\[
X=-\frac12\nabla_\mu\phi\nabla^\mu\phi,
\]

the individual terms can be expressed using the Horndeski functions
\(G_2,G_3,G_4,G_5\).

Thus this class avoids Ostrogradsky higher-time-derivative equations by
construction.

## 3. The known exact regular black-hole branch is planar

For the exact black-hole integration carried out in the 2025 work, the
two-dimensional horizon geometry is planar,

\[
k=0.
\]

The scalar profile is

\[
\boxed{
\phi'(r)=\frac1r.
}
\]

One representative resummation, corresponding to

\[
c_n=\frac{1-(-1)^n}{2n},
\]

has

\[
x(r)
=
-\frac{\ell^2}{L_\Lambda^2}
+
\frac{2M\ell^2}{r^3},
\]

and

\[
\boxed{
f(r)=h(r)
=
-\frac{r^2}{\ell^2}\tanh x(r).
}
\]

The horizon occurs at

\[
x(r_h)=0,
\]

so

\[
r_h=(2ML_\Lambda^2)^{1/3}.
\]

The exact spherical \(k=1\) branch was not integrated in that work; the scalar
profile becomes order-dependent there. Therefore the stability result below
should not be overgeneralized to every possible spherical solution of the
theory.

## 4. Background regularity

As

\[
r\to0,
\]

for positive \(M\),

\[
x\to+\infty,
\qquad
\tanh x\to1,
\]

hence

\[
f(r)\sim-\frac{r^2}{\ell^2}.
\]

Although

\[
\phi'(r)=\frac1r\to\infty,
\]

the scalar kinetic invariant is

\[
X
=
-\frac{f\phi'^2}{2}
=
\frac{1}{2\ell^2}\tanh x
\]

and therefore

\[
\boxed{
X(0)=\frac1{2\ell^2}.
}
\]

For a planar metric,

\[
ds^2=-fdt^2+\frac{dr^2}{f}+r^2(dx^2+dy^2),
\]

the core approaches a constant-curvature geometry with

\[
R(0)=-\frac{12}{\ell^2},
\]

and

\[
\boxed{
K(0)=\frac{24}{\ell^4}.
}
\]

So by background criteria alone this looks successful.

## 5. Odd-parity principal failure

De Felice and Tsujikawa derived the full quadratic odd-parity perturbation
conditions.

For the tanh-resummed model, the squared angular propagation speed is

\[
\boxed{
c_{\Omega,\mathrm{odd}}^2
=
1
-
\frac{12M\ell^2}{r^3}\tanh x.
}
\]

At the regular core,

\[
\tanh x\to1,
\]

so

\[
\boxed{
c_{\Omega,\mathrm{odd}}^2
\sim
-\frac{12M\ell^2}{r^3}
\to-\infty.
}
\]

The published kinetic quantities are also negative near the core.

Thus the regular background possesses both:

- an odd-parity ghost instability;
- an odd-parity angular Laplacian instability.

This is an explicit failure of principal-safe screening.

## 6. Even-parity strong coupling

The even-parity system contains one gravitational and one scalar physical
mode.

On the regular branch

\[
\phi'=\frac1r,
\]

the perturbation analysis finds the identity

\[
2\mathcal P-\mathcal F=0
\]

at every radius.

Consequently,

\[
\boxed{
\det \mathbf K=0,
}
\]

where \(\mathbf K\) is the even-parity kinetic matrix.

The corresponding gradient determinant also vanishes,

\[
\boxed{
\det \mathbf G=0.
}
\]

The result is not confined to the center or to one special choice of
coefficients: the analysis shows the same degeneracy for every Lovelock order
along this scalar profile and hence for the infinite tower.

Therefore this regular planar branch is infinitely strongly coupled.

## 7. Why this matters for the project

This is a second independent example of the same general lesson found in the
auxiliary-vector model:

\[
\boxed{
\text{regular metric}
+
\text{finite scalar invariants}
\not\Rightarrow
\text{regular physical perturbations}.
}
\]

The failure mechanisms are different:

### Auxiliary-vector benchmark

- hidden singular null auxiliary background;
- degenerate vector quadratic operator;
- Schwarzschild-like radial TT characteristic.

### Regularized-Lovelock scalar-tensor benchmark

- no rational curvature projector is needed;
- background scalar kinetic invariant is finite;
- nevertheless physical odd modes are ghost/gradient unstable;
- the even scalar-containing mode has a vanishing kinetic determinant.

Thus repairing covariant-lift differentiability is necessary but not
sufficient.

## 8. Status of spherical solutions

The 2025 stability paper explicitly distinguishes the known planar branch from
standard spherically symmetric black holes.

It does not prove that every spherical solution of the infinite-tower
regularized-Lovelock theory is unstable.

Accordingly the project status is:

\[
\boxed{
\text{known regular planar branch: ruled out}
}
\]

while

\[
\boxed{
\text{hypothetical regular spherical branch: unresolved}.
}
\]

Because the known nonsingular branch already sits on an infinitely strongly
coupled scalar configuration, this theory is not presently the preferred v3
candidate.

## 9. Design lesson

A viable four-dimensional screening completion must simultaneously avoid:

1. curvature-projector nondifferentiability;
2. auxiliary-field singularities;
3. vanishing physical kinetic eigenvalues;
4. negative physical gradient eigenvalues.

This pushes the search toward formulations where regularity and UV softening
occur directly in a nondegenerate gravitational kinetic operator.

# Minimal Scalar-Tensor Reconstruction: an Ansatz-Level No-Go

This note tests whether the Hayward geometry can be generated by the simplest
version of the screening idea: a single static radial scalar field with a
nonminimal \(F(\chi)R\) coupling and a standard positive kinetic term.

The result is negative under the assumptions below. This is useful: it tells us
which ingredients the next model must add.

## 1. Model

Consider

\[
S
=
\int d^4x\sqrt{-g}
\left[
\frac{F(\chi)}{16\pi G}R
-\frac12 g^{\mu\nu}\partial_\mu\chi\partial_\nu\chi
-V(\chi)
\right].
\]

Take the one-function static spherical ansatz

\[
ds^2
=
-f(r)dt^2
+
\frac{dr^2}{f(r)}
+
r^2d\Omega^2,
\]

and

\[
\chi=\chi(r).
\]

The metric equation is

\[
F G_{\mu\nu}
=
8\pi G
\left[
\partial_\mu\chi\partial_\nu\chi
-\frac12g_{\mu\nu}(\partial\chi)^2
-g_{\mu\nu}V
\right]
+
\nabla_\mu\nabla_\nu F
-g_{\mu\nu}\Box F.
\]

Here \(F\) means \(F(\chi(r))\).

## 2. Key property of the metric ansatz

For

\[
g_{tt}=-f,
\qquad
g_{rr}=f^{-1},
\]

the mixed Einstein components obey identically

\[
\boxed{
G^t{}_t=G^r{}_r
}.
\]

Therefore the difference between the \(rr\) and \(tt\) field equations must
vanish.

For the canonical scalar,

\[
T^t{}_t
=
-\frac12 f\chi'^2-V,
\]

\[
T^r{}_r
=
+\frac12 f\chi'^2-V,
\]

so

\[
T^r{}_r-T^t{}_t
=
f\chi'^2.
\]

For \(F(r)\),

\[
\nabla^t\nabla_tF
=
\frac{f'}2F',
\]

while

\[
\nabla^r\nabla_rF
=
fF''+\frac{f'}2F'.
\]

Hence

\[
\nabla^r\nabla_rF-\nabla^t\nabla_tF
=
fF''.
\]

Subtracting the two gravitational equations gives

\[
0
=
f
\left[
F''
+
8\pi G\chi'^2
\right].
\]

Away from a horizon,

\[
\boxed{
F''(r)
=
-8\pi G\,\chi'(r)^2
\le0
}.
\]

By continuity the relation extends through regular horizons.

## 3. Concavity obstruction

The equation

\[
F''\le0
\]

means that \(F'(r)\) is non-increasing.

For a smooth spherical scalar at a regular center,

\[
\chi'(0)=0,
\]

and therefore

\[
F'(0)=0.
\]

For a localized asymptotically constant scalar,

\[
\chi(r)\to\chi_\infty,
\]

so

\[
F'(r)\to0
\qquad(r\to\infty).
\]

A non-increasing function \(F'(r)\) that begins at zero and ends at zero can
only satisfy both conditions if

\[
\boxed{
F'(r)=0
}
\]

everywhere.

Then the difference equation forces

\[
\boxed{
\chi'(r)=0
}.
\]

Thus, under these assumptions, the scalar is trivial.

## 4. Why a constant scalar cannot reproduce Hayward

If \(\chi\) and \(F\) are constant, the scalar sector reduces to a cosmological
constant-like source.

But the Hayward metric is not an Einstein space at generic \(r\).

For

\[
f_H(r)
=
1-
\frac{2GMr^2}{r^3+2GM\ell^2},
\]

the symbolic calculation gives

\[
G^r{}_r-G^t{}_t=0,
\]

but

\[
\boxed{
G^\theta{}_\theta-G^t{}_t
=
\frac{
36G^2M^2\ell^2r^3
}{
(r^3+2GM\ell^2)^3
}
}.
\]

This is nonzero for \(r>0\).

So a constant scalar plus potential cannot generate the full Hayward stress
anisotropy.

## 5. Result

Under the simultaneous assumptions

1. one metric function, \(g_{tt}g_{rr}=-1\);
2. one real scalar;
3. static radial profile \(\chi(r)\);
4. standard positive kinetic term;
5. coupling \(F(\chi)R\);
6. smooth regular center;
7. asymptotically constant scalar;

there is no nontrivial localized scalar profile that supports the Hayward
geometry.

This is an **ansatz-level no-go**, not a theorem against scalar-tensor gravity
in general.

## 6. Stable radial k-essence does not immediately fix it

Replace the canonical scalar Lagrangian by

\[
P(X,\chi),
\qquad
X=-\frac12(\partial\chi)^2.
\]

For a radial static profile,

\[
T^r{}_r-T^t{}_t
=
P_X f\chi'^2.
\]

The same subtraction gives

\[
\boxed{
F''
=
-8\pi G P_X\chi'^2
}.
\]

For the standard stability sign

\[
P_X\ge0,
\]

the same concavity obstruction remains.

Thus merely replacing the canonical kinetic term by healthy radial k-essence
does not solve the problem.

## 7. Ways to evade the obstruction

At least one assumption must be changed.

### A. More general metric ansatz

Use

\[
ds^2=-A(r)dt^2+B(r)dr^2+r^2d\Omega^2
\]

without imposing

\[
A(r)B(r)=1.
\]

Then

\[
G^t{}_t\ne G^r{}_r
\]

in general, and the difference equation no longer forces the same concavity
condition.

### B. Time-dependent scalar hair

A scalar of the form

\[
\chi=qt+\psi(r)
\]

can preserve a stationary stress tensor in derivative-coupled scalar-tensor
theories while evading the purely radial derivation.

Hayward has been realized as an exact background within effective
scalar-tensor descriptions with a timelike scalar profile.

### C. Higher-derivative / degenerate scalar-tensor structure

Horndeski, DHOST, mimetic, or related constrained scalar theories add terms
whose \(rr-tt\) equation is not simply proportional to
\(\chi'^2\).

A 2025 reconstruction framework explicitly constructs covariant extended
mimetic-gravity Lagrangians for regular black holes including Hayward.

### D. Vector order parameter

A vector field carries independent radial and temporal structures and can
produce the required anisotropic effective stress.

In 2026, regular black holes including the Hayward metric were derived from
four-dimensional action principles involving vector fields. That construction
also exhibits choices with extremal inner horizons designed to avoid the
standard mass-inflation instability.

### E. Higher-curvature / nonlocal gravity

The effective anisotropy may live in the gravitational sector rather than in a
matter order parameter. This remains especially natural for the
spacetime-screening interpretation.

## 8. Consequence for this project

The original toy action

\[
F(\chi)R
-\frac12(\partial\chi)^2
-V(\chi,\mathcal I)
\]

is still useful as intuition for a phase order parameter, but it is **not**
sufficient in the simplest static radial realization.

The next minimal model should therefore test one of:

\[
\boxed{
\text{extended mimetic scalar}
}
\]

or

\[
\boxed{
\text{vector order parameter}
}
\]

before attempting a fully non-geometric completion.

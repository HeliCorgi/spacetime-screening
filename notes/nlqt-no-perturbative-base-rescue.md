# NLQT Does Not Perturbatively Repair a Bad Spherical Base

This note records a consequence of the zero-kernel and perturbative Birkhoff
results in

P. Bueno, P. A. Cano, R. A. Hennigar, Á. J. Murcia,
*Regular Black Holes in Nonlocal Quasitopological Gravity*,
arXiv:2607.07790 (2026).

## 1. Published restricted result

For spherically symmetric perturbations of a spherically symmetric QT vacuum,
the source establishes the operator identity

\[
\mathcal D
=
\hat{\mathcal D}
=
\hat{\mathcal D}^{\dagger}.
\]

For the zero-free entire form factor,

\[
\mathcal F
=
\frac{e^{\Omega(\hat{\mathcal D})}-I}
{\hat{\mathcal D}},
\]

the auxiliary linearized equation reduces to

\[
\boxed{
e^{\Omega(\hat{\mathcal D})}e=0.
}
\]

Since an exponential of an entire function has no finite zero,

\[
\boxed{
e=0.
}
\]

The remaining metric perturbation therefore satisfies the original QT
linearized equation.

Together with the QT Birkhoff/unicity property, the continuous SS vacuum
deformation stays inside the original one-parameter solution family; locally
this is a mass shift.

The source describes this as a perturbative Birkhoff theorem for NLQT.

## 2. Consequence for four-dimensional base selection

Suppose a proposed four-dimensional QT base action:

- is ill-defined on the desired regular spherical background; or
- does not possess the desired regular SS branch.

Adding the NLQT term does not provide a perturbative escape route in the
source-proven SS sector.

Near a QT background, the zero-kernel argument forces the nonlocal auxiliary
deformation to vanish, and the metric perturbation remains a perturbation of
the original QT branch.

Therefore

\[
\boxed{
\text{bad/missing QT SS branch}
\not\xrightarrow{\text{small NLQT deformation}}
\text{new healthy SS branch}.
}
\]

## 3. What remains logically possible

This does **not** prove that the full nonlinear NLQT equations possess no
additional solutions.

Possible escape routes are:

1. a disconnected/nonperturbative branch with
   \(\hat{\mathcal E}_{ab}\neq0\);
2. a branch passing through a point where the zero-kernel assumptions fail;
3. a different four-dimensional QT base representative.

The 2026 NLQT source does not construct a new disconnected regular SS branch.
Its explicit vacuum regular black holes are inherited QT solutions.

Hence the practical four-dimensional program still requires a viable QT base
action before the nonspherical NLQT stability problem can be addressed.

## 4. Relation to singularity resolution in the source

The source emphasizes that the regular vacuum black-hole background is
generated by the limiting-curvature mechanism of the infinite QT tower.
The nonlocal completion is introduced to repair the perturbative pathologies
of the local QT theory rather than to create the regular background from a
singular base solution.

This distinction matters for the current project:

\[
\boxed{
\text{base QT: background regularization}
}
\]

\[
\boxed{
\text{NLQT completion: perturbative/principal repair}
}
\]

within the explicitly constructed branch.

## 5. Current implication

The displayed 2025 four-dimensional NPQT representative now has an explicit
off-spherical Lorentzian pole in this repository.

The nonlocal completion cannot perturbatively hide that base-action problem in
the SS sector.

Therefore the next viable route is to find or construct a **different
four-dimensional QT representative** with the same useful spherical reduction
but a regular off-spherical covariant extension.

# 関係量子模型の自己修正と予測：R1

## 到達点

元のスカラー時計 q と接続網だけの模型を、そのまま宇宙の重力として採用することはしない。
今回の作業模型 R1 は、平坦背景のまわりの拘束テンソル量子場と、全物質に共通な空間分解能の結合則である。
線形ゲージ恒等式・二つの伝播偏極・静的相互作用・二体束縛状態・二物体の量子位相を計算した。
完全な非線形量子重力、一般共変な離散化、三次元真空相の創発、宇宙定数の値、ブラックホール内部の継続は導出していない。

**R1 は元の Hamiltonian の帰結を装ったものではない。二つの新しい設計仮定を追加した修正版である。**

## 1. 元の模型で実際に確認したこと

### 81 状態の局所制御模型

q_n=-2+n/20, n=0,...,80 とし、

    H(E)=8 L_81+diag(q_n^2/2+E exp(-q_n))

を再対角化した。

| E | 最低固有値 |
|---|---:|
| 0 | 0.0999218123861977 |
| 0.1 | 0.19991560896083152 |
| 0.2 | 0.2913564269668675 |

相互作用の差は -0.008552978568597866。媒介自由度を消去せず、二量子ビットと共通媒介の状態を時間発展させ、媒介を trace out すると、t=367.3097773 で negativity=0.4516345089、純度=0.9078853749 を得た。これは測定値ではなく、指定した無次元模型の計算値。

この局所制御模型には q^2/2 という固定ポテンシャルがある。元の一様 q モードの真空安定性を、この制御例から推論してはいけない。

### 一様 q の真空の傾き

元の質量ゼロ場の調和近似では、一様 q に対して

    omega_k(q)=exp(-2q) omega_k(0)
    E_vac(q)=exp(-2q) E_vac(0)
    dE_vac/dq=-2 E_vac(q)<0.

一様 q では接続上の (q_v-q_w)^2 はゼロ。従って q=0 に静止した安定な真空を置く根拠はない。
有限行列の質量ゼロ物質 Hamiltonian でも、一様パラメータ q について運動量二乗項の微分は負半定値なので、低 q 側へ自動的に復元する機構にはならない。

また、接続配置空間上の純粋なグラフ Laplacian は各連結成分の一様な振幅を零固有値に持つ。これだけで三次元幾何を優先するとは言えない。

## 2. 第一の修正：q を独立な放射自由度として残さない

対称テンソル h_mu_nu を使い、時計・座標の再記述を

    delta h_mu_nu = partial_mu xi_nu + partial_nu xi_mu

として同じ物理状態に対応させる。元の接続網からこの対称性を導いたのではなく、余分なスカラーを除くために追加した仮定である。

平坦背景 eta=diag(-1,1,1,1) の上で、二階微分までの二次 Lagrangian を

    L2 = -a (partial h_mu_nu)^2
         +b (partial_mu h^mu_nu)(partial_rho h^rho_nu)
         +c (partial_mu h^mu_nu)(partial_nu h)
         +d (partial h)^2

と置く。全運動量 p に対して Hessian K(p) のゲージ方向 R(p) が K R=0 を満たすように係数を解いた結果は

    (a,b,c,d)=(d,2d,-2d,d).

正の TT 運動エネルギーとなる d=1 を選ぶ。この作用は既知の Fierz–Pauli / 線形 Einstein 作用と同じ形になる。新規の spin-2 理論を発見したという意味ではない。

null momentum について、場の方程式の解空間は6次元、そのうちゲージ方向が4次元であり、物理的な偏極は2。
独立に3方向の空間 TT 射影子を作り、固有値が (0,0,0,0,1,1) となることも確認した。

この計数は線形・平坦背景の範囲。非線形拘束代数の閉包や三次元相の創発ではない。

## 3. 第二の修正：有限解像度を状態ではなく結合に入れる

同じ空間 Laplacian L=-nabla^2 を全物質種に使い、

    F_ell=exp(-ell^2 L/2)
    F_ell(k)=exp(-ell^2 |k|^2/2)

と定義する。これは分解能パラメータ sigma に関する

    partial_sigma A_sigma = -(1/2) L A_sigma

を sigma=0 から ell^2 まで合成した平均化。sigma は物理的時間ではない。

この追加仮定は、等方性・定数の保存・正値の平均化・分解能変更の半群合成・二階空間生成子を採用する設計である。
元の有限状態数だけから Gaussian が一意に導かれたわけではない。

空間グラフでも F=exp(-ell^2 L_Gamma/2) と書ける。17点環の行列制御で固有値が正、最大固有値1、定数保存、ラベル置換への共変性を確認した。これは三次元相の存在証明ではない。

### R1 の作業作用（c=hbar=1）

    S_R1 = S_m[eta]
           + (1/(64 pi G)) integral d^4x L2[h]
           + (1/2) integral d^4x h_mu_nu F_ell T_ren^mu_nu.

上式では L2 の係数を (1,2,-2,1) に固定する。物理的に物質が応答する線形計量は h_obs=F_ell h。

これは h の二次作用と線形物質結合までを指定した作業模型であり、非線形項を暗黙に既知とした式ではない。
T はこの近似で保存された源。実験装置を含む外部源として使う場合も保存条件が必要である。

    Box bar(h)_mu_nu = -16 pi G F_ell T_ren,mu_nu.

線形ゲージ恒等式は、平坦背景で [F_ell,partial_mu]=0 によって保たれる。
F は場と物質の同一時刻の Hermitian な結合演算子であり、非ユニタリな時間発展や測定による状態リセットではない。
時間周波数 omega の新しい極は加えない。

**代償：F は選んだ空間スライスに依存する。厳密な短距離 Lorentz 不変性・光円錐外ゼロの microcausality は保証せず、空間的に指数的な裾を持つ。線形応答は過去向きにはならないが、完全な一般共変理論ではない。**

### 真空について

独立 q の時計スケールが傾く問題は、その自由度を拘束部に置き換えることで持ち越さない。
ただし平坦背景の真空は、固定した真空基準と renormalized cosmological term で指定する。これは宇宙定数問題の解決ではない。
F(0)=1 なので、一様な真空エネルギーを平均化によって消すことはできない。
曲率依存の真空応答や相互作用の量子補正を、背景ごとに都合よく差し引くこともしない。

## 4. 同じ結合則から静的ポテンシャル

一方の源にも他方の受信物質にも F が一回ずつかかるので、交換振幅の静的カーネルは

    4 pi G exp(-ell^2 k^2)/k^2.

三次元 Fourier 変換は

    K_ell(r)=erf(r/(2ell))/r
    V_AB(r)=-G m_A m_B K_ell(r).

r=0 では K=1/(sqrt(pi) ell)。これは点源・点プローブ近似の source-to-probe カーネルである。物質分布が有限なら、さらにその形状と畳み込む。

    V_AB(r)=-G m_A m_B/(sqrt(pi)ell)
            +G m_A m_B r^2/(12 sqrt(pi)ell^3)+O(r^4).

従って中心で引力の大きさは r に比例し、無限大にならない。

    |F_r|/(G m_A m_B/r^2)
      =erf(x/2)-x exp(-x^2/4)/sqrt(pi), x=r/ell.

| r/ell | 力 / Newton |
|---:|---:|
| 1 | 0.0811085883453 |
| 2 | 0.427593295529 |
| 4 | 0.953988294311 |
| 6 | 0.999560150347 |

全距離で引力。これは source-to-probe の弱重力応答が有限であるという結果で、一般の曲率特異点の解消ではない。
必要条件は GM/(c^2 ell)<<1。強重力へ外挿してブラックホールを論じない。

Gaussian と error-function 型ポテンシャル自体には先行研究がある。今回の作業の成果は、それを選んだ一つの結合則から他の量子・光学・放射の予測まで同時に固定したことである。

## 5. 二体束縛状態

同じポテンシャルを相対運動の量子 Hamiltonian に入れる。

    H_rel = -hbar^2/(2 mu) nabla_r^2 - G m_A m_B K_ell(r).

この二体 Hamiltonian は、標準の運動エネルギーの定義域上で有界な実ポテンシャルを加えたものなので、自己共役な時間発展を持ち、

    H_rel >= -G m_A m_B/(sqrt(pi)ell)

と下から有界。通常の量子 Coulomb Hamiltonian が自己共役でないと主張しているのではなく、短距離のエネルギー依存が変わる。

x=r/ell, g=mu G m_A m_B ell/hbar^2, epsilon=E mu ell^2/hbar^2 とし、s-wave の reduced radial function u に対して

    [-1/2 d^2/dx^2-g erf(x/2)/x]u=epsilon u
    u(0)=0

を有限差分で解いた。

| g | R1 基底エネルギー epsilon | 点 Newton |
|---:|---:|---:|
| 0.1 | -0.00474776 | -0.005 |
| 1 | -0.2370753 | -0.5 |
| 10 | -4.327087 | -50 |
| 100 | -51.95975 | -5000 |

4000点と8000点で刻みを変え、最大絶対差は上記4ケースで約8.9e-6。数値表の桁は物理的精度ではない。

大きい g の展開は

    epsilon_0=-g/sqrt(pi)
              +(3/2)sqrt(g/(6 sqrt(pi)))
              -9/64+O(g^(-1/2)).

g を大きくしても非相対論的・弱計量条件を満たすパラメータ域でのみ使う。

## 6. 二物体のエンタングリング位相

二つの物体がそれぞれ位置の重ね合わせを持ち、保持された狭い波束の中心を

    A0=0, A1=d; B0=3d, B1=4d

と置く。距離行列は [[3d,4d],[2d,3d]]。

初期状態を |+>_A |+>_B とした静的投影近似では、分岐ごとの位相は

    phi_ij=(G m_A m_B t/hbar) K_ell(r_ij).

局所一体位相に不変な組合せは

    chi=phi_00+phi_11-phi_01-phi_10
       =(G m_A m_B t/hbar) DeltaK
    DeltaK=2K_ell(3d)-K_ell(4d)-K_ell(2d).

二量子ビットの concurrence は |sin(chi/2)|、negativity はその1/2。

### 位相反転の予測

    d<<ell: DeltaK=d^2/(6 sqrt(pi)ell^3)+O(d^4/ell^5)>0
    d>>ell: DeltaK=-1/(12d)+exponentially small terms<0.

従って中間に零点がある。70桁精度の独立二分法では

    d_star/ell=0.654976082565987974826915447230402808182224835251996949342304.

この桁数は指定した連続模型の数学的な根の値であり、実験的予測精度ではない。
この位置で消えるのは leading quasistatic order のエンタングリング位相。引力自体は消えず、反発にもならない。

| d/ell | ell DeltaK |
|---:|---:|
| 0.25 | +0.00449243367667 |
| 0.50 | +0.00635723725012 |
| 0.654976082566 | 約0 |
| 0.75 | -0.00646037641482 |
| 1.00 | -0.02611086507939 |
| 1.50 | -0.04490368555857 |

これは qubit 密度行列を直接作って partial transpose を取る方法でも確かめた。
有限の実験時間による sin(chi/2)=0 の偶然と違って、DeltaK=0 はこの近似では全保持時間について成立する。

### 制御条件・縮退

各分岐の質量密度が一方向標準偏差 sigma の同じ Gaussian なら、投影された二体位相では ell_eff^2=ell^2+sigma^2。
従って位相零点は 0.654976... ell_eff に動く。sigma/ell=0.05 の例で d_star/ell=0.655794291608。
物質の空間的拡がりだけでも類似した現象を起こせるので、この零点を単独で量子重力の証明とはしない。
実験解釈には波束形状・質量分布・外部ポテンシャルなどの独立校正が必要。

ここでは波束の重なり、保持装置の枝依存効果、放射、環境 decoherence を計算に含めていない。

## 7. 離散接続の誤差確認

三次元 cubic phase の Laplacian を

    k_lattice^2=4/a^2 sum_i sin^2(a k_i/2)

とした場合にも、同じ F=exp(-ell^2 L/2) を使って momentum 積分を行った。

| a/ell | 位相零点 d_star/ell |
|---:|---:|
| 0 (連続) | 0.654976082566 |
| 0.25 | 0.650020052326 |
| 0.125 | 0.653748737912 |
| 0.0625 | 0.654669965648 |

a は microscopic spacing / regulator、ell は gravitational resolution。連続式を ell 近傍まで使うには a<<ell が必要。
ell=a と同一視して上記の連続零点を高精度の物理予測とすることはできない。

## 8. 光学・放射の連動した予測

物質が応答する観測計量で、静的には Phi=Psi=-GM K_ell(r)。弱重力の直線光路近似により

    alpha(b)=4GM/(c^2 b) [1-exp(-b^2/(4ell^2))].

線積分による独立な数値積分と一致した。

自由な TT 波は omega=c|k| のまま。指定された保存源が周波数 omega で放射する canonical TT mode へのパワーは

    P_R1(omega)/P_linear-GR(omega)=exp[-(omega ell/c)^2].

これは同じ源の運動を与えた場合の比較。自己無撞着な連星の波形や、観測器の周波数応答まで計算した結果ではない。受信器の結合にも同じ F がかかる。

速度の分散と放射効率は異なるので、上式は自由波の速度変化を意味しない。

## 9. 反証可能な結び付き

ell は全ての式で同じ。一つの実験で ell を選んだ後に、束縛スペクトル、位相零点、光学応答、放射の式ごとに別の ell を当て直すことは禁止する。

仮に距離 r0 の力が点源 Newton と1%以内で一致したなら、この模型内の単純な点源条件では

    ell < 0.2099352192 r0
    d_star < 0.1375025475 r0.

これは既存実験の値を引用した制約ではなく、仮想的な1%測定に対する条件付き換算。

## 10. 未解決項を成功に数えない

- Gaussian 結合の microscopic origin と、三次元幾何相の安定性。
- 完全非線形のゲージ拘束・エネルギー運動量の Ward 恒等式。
- 一般の背景変更に対する定義、background independence、再葉層化不変性。
- 真空エネルギー・宇宙定数の値と radiative stability。
- 強重力崩壊、ブラックホール内部、一般の曲率特異点と測地線完全性。
- ell の実際の値と実験的許容範囲。

有限な二体核や平坦背景で二偏極を持つことは、上記の解決を含まない。
